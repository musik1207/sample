## この範囲で問われること

- オブジェクト権限と項目レベルセキュリティ
- プロファイル・権限セット・権限セットグループ・ミュート権限セット
- 「すべて参照」「すべて変更」などの強い権限
- ライセンスと権限の関係

## 1. 権限の積み重ね

- アクセスは **オブジェクト権限 → 項目レベルセキュリティ → レコードアクセス**の順で判定される。
- 権限は**足し算**（プロファイル＋すべての権限セット）。
- Salesforce の推奨: **最小限のプロファイル**＋**役割ごとの権限セット（グループ）**。将来的にプロファイルの権限機能は縮小し、権限セット中心になる方向。

## 2. 権限セットグループ

- 職務（ペルソナ）ごとに権限セットを束ねて割り当てる。
- **ミュート権限セット**でグループ内の特定の権限だけ打ち消せる。
- **セッションベースの権限セット**: 特定の条件（例: 多要素認証でログインしたとき）にだけ有効にする。
- **有効期限付きの割り当て**: 一時的な権限付与に。

## 3. 強い権限に注意

| 権限 | 効果 |
|---|---|
| **すべて参照（View All）** | そのオブジェクトの全レコードを参照（共有を無視） |
| **すべて変更（Modify All）** | そのオブジェクトの全レコードを編集・削除・転送 |
| **すべてのデータの参照（View All Data）** | 組織の全データを参照 |
| **すべてのデータの編集（Modify All Data）** | 組織の全データを編集 |
| **すべてのユーザーの参照** | 全ユーザーを参照（ユーザーの OWD に関係なく） |

- これらは**共有の仕組みを上書き**するので、付与は最小限に。
- **「すべて参照」のオブジェクト単位版**は、特定オブジェクトだけを見せたいときに使う（View All Data より範囲が狭い）。
- 最近は「**特定項目のすべて参照**」など、より細かい権限も追加されている。

## 4. 項目レベルセキュリティ

- 参照可能・編集可能を項目ごとに設定。**API・レポート・検索・リストビュー**すべてに効く。
- ページレイアウトの「参照のみ」は**画面上だけ**で、セキュリティではない。
- 数式項目は、参照先の項目が見えなくても、数式項目自体が見えれば結果は表示される点に注意。
