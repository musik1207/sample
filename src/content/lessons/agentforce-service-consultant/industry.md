## この範囲で問われること

- コンタクトセンターの役割と組織
- サービスの主要な KPI
- 業界ごとのサービスの特徴
- サービスの成熟度とデジタル化の方向性

## 1. コンタクトセンターの役割

| 役割 | 主な仕事 |
|---|---|
| **エージェント（オペレーター）** | 顧客の問い合わせに対応し、ケースを解決する |
| **スーパーバイザー** | チームの稼働状況を監視し、エスカレーションや指導を行う |
| **ナレッジ管理者** | 記事の作成・レビュー・公開を管理する |
| **サービスマネージャー** | KPI と運用方針を決め、改善を進める |
| **システム管理者** | ルーティング・チャネル・自動化を設定する |

- **Tier（階層）**: Tier 1 で一般的な問い合わせ、Tier 2・3 で専門的な問題を扱う。

## 2. 主要な KPI

| KPI | 意味 |
|---|---|
| **初回解決率（FCR）** | 最初の対応で解決した割合。高いほど良い |
| **平均処理時間（AHT）** | 1 件あたりの対応時間（通話＋後処理） |
| **顧客満足度（CSAT）** | 対応後のアンケートでの満足度 |
| **NPS** | 他人に勧めたいか（推奨度） |
| **サービスレベル** | 決められた時間内に応答した割合（例: 80% を 20 秒以内） |
| **放棄率** | つながる前に顧客が離脱した割合 |
| **自己解決率（デフレクション）** | ナレッジやボットで、ケースを作らずに解決した割合 |
| **エスカレーション率** | 上位の担当に引き継いだ割合 |

KPI は**互いにトレードオフ**がある（AHT を下げすぎると FCR や CSAT が下がる）ので、組み合わせて見る。

## 3. 業界ごとの特徴

- **金融**: 本人確認、規制対応、監査証跡が重要。
- **医療・ヘルスケア**: 個人情報の厳格な保護。
- **小売・EC**: 問い合わせ量の季節変動、注文・返品の連携、チャットやメッセージングが中心。
- **製造・ハイテク**: 製品・資産（Asset）・保証・保守契約の管理、フィールドサービスとの連携。
- **公共**: アクセシビリティ、多言語対応。

## 4. サービスのデジタル化

- **セルフサービス**（ヘルプセンター、ナレッジ、AI エージェント）で簡単な問い合わせを自己解決。
- **オムニチャネル**で、どのチャネルでも同じ顧客情報で一貫した対応。
- **予防的なサービス**: 問題が起きる前に知らせる（IoT や利用データの活用）。
